# VEEP (Vinyl Bee Beep Player)

レコードのアナログな魂と、鋭くモダンな「Bee（蜂）」のエッセンスを融合させたプレミアム・オーディオプレーヤー。

## 🐝 コンセプト
`concept` ファイルのキーワードに基づく設計：
- **Vinyl**: クラシックなターンテーブルの機構とアナログの温かみ。
- **Bee / Beep**: 高コントラストでエネルギッシュなヴィジュアル・アイデンティティ。
- **Player**: 高品質な `.wav` 再生に特化した機能性。

## 🎨 ビジュアル・アイデンティティ
- **カラーパレット**: 深みのある **Black**、鮮やかな **Yellow**、そして高級感のある **Gold**。
- **「Bee」スタイル**: シャープなライン、高コントラストなUI、そして蜂の巣のような精密なデザイン。

## ✨ 主な機能
- **33.3 RPM レコード回転**: 物理法則に基づいたスムーズなヴァイナル・アニメーション。
- **スティンガー・トーンアーム**: 再生開始時に精密に動く、蜂の針（Stinger）をイメージしたスタイラス。
- **ハニー・ビジュアライザー**: `.wav` ファイルの音に連動して波打つリアルタイム周波数バー。
- **プレミアム・グラスモーフィズム**: 洗練された透明感を持つ、モダンな操作パネル。

## 🕹️ 操作方法
- **読み込み**: `.wav` ファイルをドラッグ＆ドロップ、または選択。
- **再生/一時停止**: レコード盤をクリック、または `Space` キー。
- **音量**: 精密なハニーゴールド・スライダーで調節。
