# Vinyl Wav Player (Yane Player) 仕様書

## 1. 概要
ヴィンテージ風のレコードプレーヤーを模した、プレミアムなWebベースのオーディオプレーヤー。主に `.wav` ファイルの再生に最適化されており、アナログレコードの操作感と視覚的な楽しみをデジタルで再現します。

## 2. 技術スタック
- **フロントエンド**: HTML5, CSS3 (Vanilla CSS), JavaScript (ES6+).
- **オーディオ処理**: Web Audio API (周波数解析およびリアルタイム・ビジュアライザー用).
- **タイポグラフィ**: Google Fonts (Outfit, Playfair Display).

## 3. 主な機能

### 3.1. 視覚的演出
- **ターンテーブル・デザイン**: ダークな筐体に真鍮調（メタリックゴールド）のアクセントを加えた高級感のある外観。
- **グラスモーフィズム**: 背景ぼかしを利用した、コントロールパネルの半透明デザイン。
- **ダイナミック・アニメーション**:
  - **レコード回転**: 再生中、毎分33.3回転 (1.81秒/回転) でスムーズに回転。
  - **トーンアーム（針）**: 再生開始時に針がレコードの上に移動し、停止時に戻るアニメーション。
  - **ステータスLED**: 動作状況（再生・一時停止・待機）に合わせて色が変化するインジケーター。

### 3.2. オーディオ機能
- **対応フォーマット**: `.wav` ファイルに特化。
- **再生コントロール**: 再生、一時停止、停止の基本操作。
- **音量調節**: リアルタイムでゲインを調整可能なスライダー。
- **ビジュアライザー**: `AnalyserNode` を使用した、音の高さに連動する30本の周波数バー。

### 3.3. UX & ショートカット
- **直感的操作**: レコード盤そのものをクリックすることでも再生/一時停止が可能。
- **キーボード対応**: `Space` キーで再生/一時停止を切り替え。
- **メタデータ表示**: ファイル名を取得し、レコードのラベルとパネル上に表示。

## 4. デザイン定数
- **メインカラー**: `#d4af37` (ゴールド)
- **背景色**: `#121212` (チャコールブラック)
- **回転数**: `1.81s` (33.3 RPM)
